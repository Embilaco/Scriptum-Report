# Third-party material in the test fixtures

Nothing under `tests/` ships in a distribution artifact — the sdist and the
wheel prune the test tree (`MANIFEST.in`; `Distribution.md` has the details) —
so these credits concern the repository itself.

The following test fixtures include third-party material. The images may be
scaled or cropped from their sources for test use.
